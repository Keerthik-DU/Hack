# ADR-004: Gitleaks / Secrets Patterns DB as Pattern Source

- **Status:** Accepted
- **Date:** 2026-08-12

## Context
Need broad, maintained secret patterns for MVP.

## Decision
Port 100+ patterns from Gitleaks/Secrets Patterns DB into PatternRegistry.

## Consequences

### Positive
- Industry-standard coverage

### Negative
- External pattern maintenance dependency
