# ADR-007: Vite 5 + React 18 + TypeScript 5 Toolchain

- **Status:** Accepted
- **Date:** 2026-08-12

## Context
Need fast HMR and first-class Worker support for a static SPA.

## Decision
Standardize on Vite 5.x, React 18.x, TypeScript 5.x.

## Consequences

### Positive
- Fastest HMR and native ESM

### Negative
- Smaller plugin ecosystem than Webpack

- Next.js`n- Webpack 5`n- Parcel
