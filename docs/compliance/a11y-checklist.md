# WCAG 2.1 Level A Checklist (WO-065)

- Keyboard: all interactive controls focusable and operable
- Name/Role/Value: buttons, progressbars, textareas expose accessible names
- Color: status not conveyed by color alone (text labels on StatusBar)
- Images: decorative icons aria-hidden; meaningful have alt
- Live regions: EarlyFindings / progress use aria-live where appropriate
- Contrast: theme tokens meet AA for body text (verified visually + axe)
